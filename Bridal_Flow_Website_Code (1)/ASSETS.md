# Included assets

All display assets are local files in public/.

| File | Contents |
| --- | --- |
| bridal-yoga-calm.webp | AI-created bridal group seated in a country-house room |
| bridal-yoga-together.webp | AI-created group preparing for yoga |
| yoga-details.webp | AI-created mats, linen and flowers |
| cara-garden.webp | Creative composite using Cara's supplied face, pose and garden references |
| cara-terrace.webp | Creative composite of Cara on a terrace, with the Bridal Flow title |

Each image also has a -small.webp variant. Images are converted to WebP and resized for web delivery without changing their content. Group imagery is not represented as photographs of actual clients. The gallery explains how these images were made.

DM Sans and Italiana font files are supplied under the SIL Open Font License. Their licence texts are included as public/LICENSE-DM-Sans.txt and public/LICENSE-Italiana.txt. The typefaces were downloaded from Google Fonts. No external image/font request is needed to render the site.
